# WOMS — Frontend

Frontend of the **Well Operations Monitoring System (WOMS)**, an academic team project developed at ESI Algiers during the 2024/2025 academic year.

## About

WOMS is a web-based platform designed to improve the monitoring and management of oil drilling operations.

The application provides interfaces adapted to field operators and decision-makers, allowing them to monitor drilling activities, operational reports, costs, deadlines and performance indicators.

## Technologies

- React.js
- JavaScript
- REST APIs
- Figma

## Main Features

- Drilling operations monitoring
- Operational dashboards
- Cost and schedule tracking
- Planned vs. actual deviation visualization
- Report submission and consultation
- Alerts and anomaly monitoring
- Role-based user interfaces

## Architecture

This repository contains the **frontend** of the WOMS platform.

The frontend communicates with a Spring Boot backend through REST APIs.
